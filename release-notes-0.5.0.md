# Adventurer Guide 0.5.0

First public release. An NPC in Prontera (136,171) that tells each class where to level, what gear and cards to get, which stats and skills to take, which MVPs to consider and what the server's rates are. Pre-renewal and renewal each get their own data.

## New

- **Where to level:** level spots for every level range (10 pre-renewal, 17 renewal), each with the monsters, the map ids and a hunting tip for your class (spells to use or skip, trap lines, Grimtooth crowds, Pierce on Large monsters, Turn Undead and so on).
- **Gear and cards:** a buy list with prices and towns (starter tiers plus everything else your class can buy), weapon cards, weapons only monsters drop (slotted versions of shop weapons, element katars / bows / whips / guitars, skill-bonus weapons), armor / shield / garment / shoes / accessory / headgear cards, armor and accessories only monsters drop, and a general card guide (race and element damage, race defence, elemental armor and garments, status immunities). Each pick shows the monster, its level, the drop rate and the map. Gear your class cannot wear is left out.
- **Stats and skills:** builds for the first class and every 2nd-class line, with several playstyles per line, rebirth pages, third-class summaries in renewal and a note on the rules of the current mode.
- **Bosses (MVP):** MVPs by level range with element, HP, map and card, a cautious rating for your class, and a page of the skills to watch for with what helps.
- **Server rates:** EXP and drop rates read live from the server, and what the card rate means in kills per card.
- Class detection for Novice / Super Novice, Swordman, Mage, Archer, Acolyte, Merchant, Thief, Taekwon, Gunslinger and Ninja lines (rebirth and baby classes use their base line); any other class page can be opened from the menu.
- One setting: a custom NPC view id (0 = the default old crusader).

## Notes

- Needs Ragnarok Offline 1.4.3 or newer. Copy the folder to `%APPDATA%\Ragnarok Offline\state\mods` (or use Settings → Mods → Add mod from folder), switch it on and press Apply.
- Level spots, drops, prices and boss data come from the app's own server data. Builds are classic community advice, and the MVP ratings are a rough pointer only.
- Doram and Gangsi have no page yet.
- Not every page has been checked in game in both modes; reports are welcome.
